AI CampusMate — Intelligent College Assistant

A unified academic management platform and Google Gemini-powered conversational assistant connected to MIET's relational MySQL database (ai_database) for real-time attendance, timetable, results, circulars, and coursework.

01. Personalized Student Isolation
Individual CS Semester 5 records for Gauri, Harshi, Pranjal, and Manvi retrieved by authenticated database ID.
02. Real-Time MySQL CRUD
Faculty administrators manage notices, assignments, lectures, attendance, SGPA/CGPA results, and campus events.
03. Grounded Gemini AI Assistant
Answers natural-language queries using live student attendance, timetable, and exam records from MySQL.
04. AI Circular Summarizer
Extracts executive bullet points, compliance deadlines, and student action items from official notices.

B.Tech Academic Project · Stack: HTML5 · CSS3 · Vanilla JavaScript · Python Flask · MySQL · Google Gemini API
